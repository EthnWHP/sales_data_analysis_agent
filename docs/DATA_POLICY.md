# 数据与公开范围

`sales.csv` 与 `create_data.py` 中固定字典一致，共 9 条合成记录，不含客户或员工标识。根目录的两张旧图月份排序不正确，继续排除。`docs/assets/sales_profit_line.png` 由当前离线演示根据相同样例重新生成，月份按 Jan、Feb、Mar 排序，是唯一允许提交的演示图片。

`.env`、私钥、虚拟环境、日志、Redis 数据、真实业务表格、历史会话及未审查的个人 `SKILL.md` 默认不进入仓库。现有本地 `.env` 保留，公开配置以空密钥的 `.env.example` 为准。

若替换数据，应先移除客户姓名、联系方式、订单号、员工信息、公司内部指标和其他不可公开内容。即使只上传图表，轴标签、图例、数值也可能泄露信息。不要把私有数据覆盖到公开样例文件后直接提交。

执行模型入口会将用户问题、对话上下文和模型取得的工具结果发往配置的模型服务。Redis 版本会在指定 Redis 中持久化会话。更改服务地址之前确认该服务的使用权限与数据处理安排；不要使用未经授权的业务数据。

新增文件必须审查后才可公开。`.gitignore` 仅阻止未跟踪文件被普通添加，不会撤回已经提交的内容。若凭据曾进入仓库历史，先撤销或轮换凭据，再按实际仓库情况处理历史。
